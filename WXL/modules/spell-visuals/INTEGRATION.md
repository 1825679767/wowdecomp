## Native ownership and lifecycle

WxlSpellVisuals is a separate object module with a default-ON private compile option `WXL_ENABLE_RETAIL_SPELL_VISUALS`, linked into WxlNative and enumerated by ModuleApi. Its dependencies are runtime/storage/DB2/M2/protocol. The runtime CVar `wxlRetailSpellVisuals=1` enables presentation;0 clears owned presentation on the next owner tick. Registration/UI startup run outside the ClientExtensions feature guard, so disabling unrelated helper APIs does not remove this donor bridge.

The single catalog worker performs only DB2/FDID/storage work and publishes owned values under a mutex. It is never detached. Shutdown joins it before EventDestroy, CVar destruction and CloseAllArchives. Native models and Lua run only from the existing owner Lua update boundary. No worker resolves units, accesses model state or executes Lua.

Pending requests preserve the donor250ms retry/minimum duration, expiry and replacement-by-GUID rules. Limits are64 pending requests,64 graph choices,256 active models,255-byte model paths and an INT32_MAX duration ceiling so wrap-safe deadline comparison remains valid. Invalid/out-of-range graph results refuse rather than produce partial attachments. Atomic attachment groups reserve ownership first and release only their own partial group on failure. File absence/native ErrorCube fallback names never become accepted visual instances.

Each active visual holds an ordinary native reference to its root and its created CM2Model. Native AttachToParent supplies the parent reference; retirement detaches/releases only that owned child, then releases its root reference. It never calls broad DetachAllChildrenById or manipulates another attachment owner's slot. Tick resolves the exact GUID again and compares the current unit model/root handle, parent binding and child shared filename. Expiry, STOP, feature disable, Lua context reset, transport generation change, map change, world leave, owner disappearance or root replacement retire it. WorldLeave runs before LoadNewWorld/ClientDestroyGame object teardown; FrameScript teardown also clears it.

CM2Scene's destructor forcibly releases models regardless of external reference count, so a narrow ReleaseScene hook runs before that native force-release loop. It retires only this module's models in that scene; this prevents stale references during unexpected scene retirement or shutdown. No native world/fog/liquid/weather draw, lifetime or state authority is replaced. Native scene creation/attachment/animation/light/render/resource paths remain the consumer. Per-tick placement normalizes only the owned model's local world-matrix basis through SetWorldTransform, retaining its rotation/translation and matching donor per-frame scale normalization.

`wxlRiftPlayback=0` preserves the actual donor default. Value1 enables the donor boolean startup213->hold158 policy; there are no invented modes0/1/2/3. The four original source sequence indices are0..3 with IDs213/0/158/159. Playback waits for model readiness, original exact source identity, native four-sequence IDs/durations, native bones and HasSequence. It requests213 once, then158 after1000ms, without freezing clocks, changing expiration or restarting on retries. Native sequence assembly may resolve source aliases/flags, so runtime checks the normalized IDs/durations while the retained exact original-file identity proves the original donor sequence contract.
