# Native exact-source Blood Boil refraction candidate

Source-only, experimental donor compatibility; no build, installation, gameplay or pixel acceptance. Baseline native commit: `730373071586086e21d52858841bd2a73a4ac62b`. This stage changes no shared source. Merge individual patch hunks with the concurrent particle-tail and equipment work; do not overwrite whole source files blindly.

The donor is `extensions/wxl-modern-m2/src/render/ParticleRefraction.cpp`, `RefractionAttributionPolicy.hpp`, `ParticleRefraction.hpp`, and `shaders/BloodRefraction.ps.hlsl` with its exact compiled `src/render/shaders/BloodRefractionPs.h`. It implements a bounded height-gradient approximation, not the retail refraction equations. The original compiled pixel shader is copied unchanged into the overlay.

Admission captures immutable source emitter zero before normalization only for `spells\cfx_deathknight_bloodboil_castworld.m2`, MD21/inner MD20 version 274/global flags 0x3090, seven emitters, six textures, six TXID entries, source emitter flags 0x60931011/blend 4/texture index zero and height TXID 1601218. The original complete emitter record remains owned by ModelAssets and is shared with that emitter's native Params. Native emitter cloning naturally retains the recipe through Params copy; texture references, particle simulation, sort/twinkle, geometry, index order and instance replacement remain native. No generic conversion admission, material blend table, flags grant, or world/fog/liquid callback changes are introduced.

The exact emitter is excluded from multi-emitter batching. Its existing native RenderParticleVertices function establishes native VB/IB, default shaders and transforms; the new consumer runs immediately before the original native Draw. Actual selected D3D VS/PS GetFunction bytes must match the donor retained NativeUnlit and NativePixel. Stream stride must be 24, format PCT, native height texture present, depth write off, texture-zero sRGB read off, target sRGB write off, and the batch must be 4..4096 quad vertices with the original six indices per quad. Unsupported draw shapes or native contracts retain the donor's native fallback.

On a supported draw the consumer copies ACTIVE RT0 immediately before this emitter, requires a full-target viewport, and allocates a same-dimension/same-format render-target texture. StretchRect uses NONE filtering and preserves the donor's MSAA resolve behavior. It deliberately does not call the native TexCopy helper because that helper reads m_defColorSurface rather than active RT0. No capture from a prior frame is ever consumed: every custom draw requires a successful current capture.

The resource owner is a shared_ptr field on the actual native CGxDevice, containing only texture/surface COM ownership and dimensions/format. It saves no raw device pointer. D3D9 and D3D9Ex IReleaseD3dResources release it before their existing reset/resource teardown; GxDevDestroy explicitly releases it and the persistent device-list pixel shader. Resize/format changes create a replacement capture, and failed replacement/copy never uses stale content. The native device shader cache retains one shader reference; draws do not create and destroy shader programs repeatedly.

Pixel constants c0 are the exact donor values `(1/width, 1/height, 64, 4)`. The original native vertex shader and all geometry bindings remain selected. The shader samples height red-channel screen derivatives, clamps displacement to four pixels, modulates it by vertex alpha, applies the donor half-pixel screen coordinate convention, and samples the current scene. Scene sampler one is clamp/linear/no-mips/non-sRGB. Alpha blending, alpha testing and fog are disabled only inside this draw, and RGB-only color writes preserve target alpha. Texture one, its six changed sampler states and four changed raw D3D render states are captured and restored exactly; their native caches are untouched. Native RsPush/Pop and ShaderConstantsSet restore the selected pixel shader and shadow-cached c0, followed by typed backend IStateSync. No texture flags are modified. An actual backend restoration failure suppresses the affected emitter and disables custom refraction for the session; ordinary fallback is permitted only after restoration.

`WXL_ENABLE_BLOOD_REFRACTION` defaults ON and is a PRIVATE definition on WxlParticles, avoiding unrelated module recompilation. `wxlBloodRefraction` defaults 1, accepts 0/1, and 0 immediately routes the emitter through its existing layer/cutoff/native branch. The existing wxlParticles switch is also honored. Compile-off leaves public registration/lifecycle functions available while source capture declines the family. The native device must be D3D9 or D3D9Ex with the retained shader capability contract; DX11/OpenGL remain unsupported. This is one named source recipe, not general Blood/refraction/mesh support.

Remaining validation is the parent's combined native build, then source-compatible Blood Boil asset availability, in-game visual comparison and capture proof, successive emitters/frames, reset/lost-device, resize/MSAA/format behavior, world leave/reentry, rollback CVar, and surrounding particle/world/fog/liquid state regression. A successful compile or applied log does not establish visual acceptance. No release assembly, acceptance promotion, installation, publication or upload is performed by this stage.

`candidate.patch` contains the complete code delta; `overlay/` contains complete candidate files and `baseline/` preserves the exact input files for manual three-way merges. `references/` contains hashed donor/native evidence used to establish the contracts. `input-hashes.json` records every baseline/evidence file and its source path; `output-hashes.json` records staged candidate output identities. Neither source snapshot nor static review is a binary build-source binding.
