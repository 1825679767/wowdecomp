# Native layered particles - pending source stage

The default-on Particles module now captures and renders a bounded three-texture donor family through native Gx. No injected offsets, x86 hooks, raw D3D device calls or global device replacement are introduced. DX11 and OpenGL implementations remain deferred. Models carrying unsupported multilayer contracts fail conversion; a supported recipe that loses runtime shader/texture readiness submits no first-texture fallback.

## Exact admitted subset

MD21 inner version274 with global flags0x3090, source MultiTexture flag, unlit ordinary-alpha blend2 head-only sprites, unsigned scale bytes, three file textures, empty geometry/child model names, neutral emitter TXAC, and no source Modx4/depth/refraction variant bits. The implementation does not interpret arbitrary auxiliary chunks. TXAC mesh rows are preserved and do not disqualify an otherwise neutral particle unless the independent EXPT converter's existing all-neutral rule applies. EXPT/EXP2 scalar and cutoff validation remains with ApplyParticleExtensions.

D3D9/9Ex must expose SM3 vertex/pixel targets, at least35 vertex constants and three texture units. Runtime also requires native shaders enabled, unlit ordinary alpha state and a four-vertex/six-index native particle shape. No OpenGL reinterpretation of D3D bytecode occurs. This subset is intentionally narrower than the old donor experiments: signed scales, SourceRGBModulationCandidate, TXAC1/1, BlendAdd/Screen, refraction and lit/shadow variants are not asserted to be recovered.

## Capture and ownership

CaptureParticleLayers runs before M2Bytes::Convert and retains every admitted emitter's entire modern source record, original flags, packed texture indices, TXAC presence/row, both scale values and both scroll mid/range vectors. Three packed five-bit indices decode without losing the second and third texture. Captured source emitter count must match the normalized count. Sidecars live in native ModelAssets and are immutable shared_ptr recipes. Nonzero EXP2 cutoff accepts a layered emitter only when the exact admitted recipe record/flags still match its source bytes.

InitializeLoaded attaches both the immutable recipe and a binding with three HandleDuplicate texture references from that CM2Model instance texture table. Params copy construction carries both references into native emitter clones. ReplaceTexture refreshes all three references from the modified instance table after native replacements, so secondary/tertiary handles and clones do not retain shared-source or other-instance textures. A failed replacement binding keeps the required-recipe flag and suppresses that draw. Native handle close in the binding destructor releases each duplicate, including repeated texture identities; a clone can retain its binding after the original shared source dies. Allocation/readiness failure cannot clear the separate required recipe flag and thereby fall back to the normalized first texture.

## Vertex and shader implementation

Native BuildVertex remains authoritative for positions, atlas UV0, color/alpha, billboard, scale, spin, depth order and twinkle rejection. Immediately after each successful four-vertex native build, the adapter validates its four atlas corners and appends UV1/UV2 independently. Records stay in the native sorted order and every actual rendered particle contributes exactly four40-byte vertices. Any shape/UV failure invalidates the entire layer draw. Layered emitters are excluded from cross-emitter pooling in both the first-emitter dispatch and subsequent batch scan.

The extra-layer equations are ported from donor ParticleLayerPolicy Motion/ExpandQuad: sign-magnitude scroll divided by512; unsigned scale divided by32; independent deterministic starting offsets; velocity=mid+range*random; UV=start+velocity*particleAge+corner*scale. The native particle's stable randomSeed seeds this donor deterministic motion without advancing emitter RNG. This is a functioning donor composition policy; exact retail RNG sequence/parity is not claimed. Atlas UV0 remains the native mask UV rather than being forwarded into both extra channels.

The exact donor ParticlePrograms.hpp is retained with its generated SHA256 comments, together with original ParticleLayers.vs.hlsl and .ps.hlsl. The actual Unlit VS and TwoColorThreeAlpha/ThreeColorThreeAlpha PS compiled arrays are submitted through native CGxShader objects registered in the native device shader list, validated through its IShaderCreate/Valid path and destroyed through ShaderDestroy. No shader compiler or guessed FileDataID is required. The two-color kernel multiplies layer0/1 RGB and all three texture alphas; the three-color kernel multiplies all three RGBA samples. Color/alpha extension multipliers already baked into native keys are not applied twice.

Native custom PrimVertexFormat supplies Position(type4,offset0), Color0(type0,offset12), UV0/1/2(type3,offset16/24/32), all stride40; PrimVertexMask enables exactly those semantics. Native D3D9 IStateSyncVertexPtrs computes the stream stride as12+4+8+8+8=40, creates/caches the custom declaration from those semantics and retains existing buffer/index base-offset handling. No enum is repurposed and no built-in format is changed. Draws use the existing native quad index buffer and count/ranges bounded by16384 vertices.

## State and cutoff

Native ShaderEffect uses the same projection(c2..5), UV0(c6..7), fog(c30) and model rows(c31..) ABI as the retained donor Unlit program. UpdateProjMatrix, SetTexMtx_Identity and UpdateWorldViewMatrix populate its draw constants. Current c30 fog visibility and PS c2 fog RGB remain native SetupMaterial authority, including the native disabled-fog constant. PS c0=(1,1,max(nativeAlphaRef,lifetimeCutoff),0), so normal alpha blending/fog remains and cutoff clips the composed alpha. Adjacent identical thresholds can share draws without reordering particles.

DrawScope retains native cached vertex attributes/mask/index, view, shader selections through RsPush/RsPop, PS c0/c2 and VS c2..7/c30..34. It restores through the same native ShaderConstantsSet and render-state APIs, forcing texture-unit cache updates and syncing restored programs before releasing draw-local registered shader refs. Pixel c2 and vertex c30 are reasserted from their saved native values after texture readiness; no replacement fog function is introduced. Each bound texture's original flags are captured before changes, temporary wrap/linear-point-mip sampling is restored per texture (including repeated identities), and native stages0..2 are forced through cache restoration. Temporary extended vertices use native streamed-buffer ownership.
