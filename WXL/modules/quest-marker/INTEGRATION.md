## Scope

Ports actual `extensions/wxl-quest-marker` donor behavior: request 101/102/103 on outgoing 0x51f; exact 36-byte marker, up-to-four-entry kill list, and 4/28-byte corpse decoding on 0x520/0x536/0x537. All four opcodes register atomically through NativeProtocol before the legacy packet facade. Those IDs are removed from the facade declarations. Existing `CanLegacySend/CanLegacyObserve` also exclude compiled owners, so custom-packet Lua cannot send or drain this stream. Default-on CMake option `WXL_ENABLE_QUEST_MARKER`, runtime CVar `wxlQuestMarker`, feature bit 4096, and object target `WxlQuestMarker` preserve independent module controls. Public `QuestMarker.hpp` uses C++17-compatible declarations; private implementation uses C++20.

The module preserves `wxlwow.quest_tracker.Request/PopMarker/PopKillEntries/PopCorpse`, deferred `_NativeChanged`, `_FrameXMLReady`, and existing SetQuestMarker/ClearAllQuestMarkers/GetDistInfo/SetMarkerAlpha/QuestTrackerReloadSettings/SetCorpseMarker/ClearCorpseMarker/IsCorpseActive/GetCorpseDistInfo/SetDeadState/GetPlayerPosition/SetTrackerDiamond functions. UI owner-thread queues cap at 256 marker/32 kill/16 corpse packets. Malformed sizes, nonfinite or float-overflow coordinates, invalid flags/types, and bad request argument types are rejected. Session/map changes clear inbound and presentation state independently, including when a packet arrives before the next UI update. UI reload destroys presentation state without unregistering transport-owned declarations.

Typed source APIs replace all donor absolute addresses, hooks, inline assembly, object offsets, and D3D device pointers. NativeProtocol::Capture checks IsOwner before invoking compiled handlers under its mutex; Receive therefore accesses native ObjectMgr only on the owner thread, takes only its own mutex, and never calls Lua or reenters protocol APIs. Notifications run later outside both locks.

Objective rings use typed visible-object enumeration, `CGObjectData::m_entryID`, health/model/type checks, native per-unit selection radius and rotation matrices, `ProjectTex::Render2d`, and a matching WorldFrame world-pass seam. Donor limits of 60 yards, 24 circles, radius .5-30, fixed FFFFC800 color, .40 brightness, .85 opacity, and the custom quest ring BLP are retained. Gx state is pushed before the native selection-state setup and popped after enumeration; no normal target-selection method or texture owner is modified.
