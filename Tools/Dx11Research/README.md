# Standalone DX11 shader research

This independent CMake project builds the bounded v4 GXSH container reader, its malformed-input tests, a DXBC inspection tool and a WARP offscreen rendering proof. It does not construct a game `CGxDeviceD3d11` or change game API selection.

Build with CMake/Visual Studio x64. `ctest -C Release --output-on-failure` runs the parser suite and WARP proof without launching a client. The top-level `E:/WXL1.1/dx11/README.md` records the frozen input export, build binding, actual results and remaining integration.

Container semantics follow the local Cataclysm reference `959b0b85c5f55c565328d7c3ca33027a65e41327`, with checked tables and exact decompression accounting added. Counts, lengths and allocations are bounded; all decoded metadata remains opaque until a family-specific contract is established. Legacy Wrath `0x10003` input is rejected explicitly. Synthetic proof containers use shader bytecode generated by Microsoft's HLSL compiler; they are not game shader assets.
